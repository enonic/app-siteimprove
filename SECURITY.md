# Security Policy

## Supported versions

| Version | Enonic XP | Supported |
|---------|-----------|-----------|
| 2.x     | 8.x       | Yes       |
| 1.x     | 7.x       | Yes       |
| < 1.7.1 | 7.x       | No, upgrade to 1.7.1 or later |

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use one of these private channels instead:

- [Report a vulnerability](https://github.com/enonic/app-siteimprove/security/advisories/new) on GitHub, which opens a private draft advisory visible only to the maintainers.
- Open a ticket at [support.enonic.com](https://support.enonic.com) if you are an Enonic customer.

Include the affected version, the steps to reproduce and, if possible, a minimal example.
You will get an acknowledgement within two working days.

Fixes are released as patch versions for every supported line and published on
[Enonic Market](https://market.enonic.com). Once a fix is available, the advisory is published
on the [Security](https://github.com/enonic/app-siteimprove/security/advisories) tab with
a CVE, and the reporter is credited unless they prefer otherwise.
